# Architecture Decision Records

Ogni decisione architetturale non ovvia si registra qui come ADR numerato (`NNNN-titolo.md`), secondo [ADR 0001](0001-registro-decisioni.md).

| ADR | Titolo | Stato |
| --- | --- | --- |
| [0001](0001-registro-decisioni.md) | Registro delle decisioni architetturali | Proposto |
| [0002](0002-nucleo-cpp-juce.md) | Nucleo e moduli desktop in C++ con JUCE | Proposto |
| [0003](0003-interfacce-di-controllo.md) | Interfacce e app sui dispositivi | Proposto (scelta aperta) |
| [0004](0004-ambiente-di-build.md) | Ambiente di sviluppo e di build | Proposto |
| [0005](0005-licenza.md) | Licenza del progetto e delle dipendenze | Proposto |
